# Ex-Ficha

> Ela te trocou. E você? Nem a ficha de treino troca.

App de treino para quem acabou de sair de um relacionamento: ficha nova, contador de dias desde o fim, botão de pânico antes da mensagem e uma zoeira ácida que não deixa você parar.

## O que tem aqui

| Pasta | O que é |
|---|---|
| [`canvas/`](canvas/) | Canvas estilo Figma com todas as telas do app, componentes, banco de 100 frases, marca, landing page e prints da loja. Abra `canvas/index.html` no navegador. |
| [`app/`](app/) | O app em Expo (iOS, Android e navegador): onboarding, ficha, treino, pânico, biblioteca, evolução. Veja o README da pasta. |
| [`exercicios/`](exercicios/) | Base de 42 exercícios em português com GIFs do ExerciseDB no tratamento sombrio da marca, e o script que a gera. |

## Canvas
- Arraste qualquer tela pra mover (as posições ficam salvas no navegador). "Reorganizar" volta ao padrão.
- "Protótipo" (ou dois cliques numa tela) abre o fluxo clicável.
- "Fluxo" mostra as setas entre telas e "Comentários" mostra as notas de design.
